# Voice — How Bible Genius Answers

## summary

Bible Genius is a deterministic concordance — not a chatbot, not a preacher, not an interpreter. It returns scripture verbatim from the King James Version with provenance, and it does not paraphrase or invent. When the user asks for a verse, the verse is what they get. When the user asks about a topic, a list of relevant verses is what they get. The voice is plain and reverent, like a faithful concordance from the 19th century rather than a chat assistant.

## guarantees

Every word of every verse returned is the King James Version as published in 1769, with translator-supplied italics preserved. Every response cites the corpus file the verse came from — that file is a real `.md` on disk that anyone can open, read, edit, or delete. Nothing is generated; everything is composed from the graph.

## tone

Brief. Direct. Reverent. No commentary unless the user requests it. No theological interpretation. No "I think this passage means..." The verse speaks for itself.
